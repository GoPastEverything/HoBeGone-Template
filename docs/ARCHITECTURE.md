# ARCHITECTURE: FollowerIntegritySkill v0.6

```
Template UI (templates/ho-be-gone, skills/) -> FollowerIntegritySkill (python3 -m fis) -> X/browser operator (operator_prompts/)
  -> Evidence store (fis/evidence_store.py, SQLite) -> Feature extractor (collection records + fis/pipeline.behavior_extraction)
  -> Scoring engine (fis/scoring.py wraps frozen engine.py) -> Network analyzer (fis/network.py + v0.5 fingerprints_db.json)
  -> Human-continuity analyzer (fis/continuity.py) -> Second-pass verifier (fis/second_pass.py) -> Decision engine (fis/decision_engine.py)
  -> Owner adjudication (fis/adjudication.py) -> Enforcement executor (fis/enforcement.py + operator_prompts/block_batch.md)
  -> Audit database (audit_events) -> Metrics/calibration (fis/metrics.py, fis/calibration.py) -> Export (fis/export.py)
```

| Stage (spec order) | Code / operator | Module |
|---|---|---|
| DISCOVERY | operator (browser) + checkpoint order | operator_prompts/discovery.md, fis/checkpoint.py |
| ACCOUNT_COLLECTION | operator (browser), validated by code | operator_prompts/collection_batch.md, schemas/account_record.schema.json |
| BEHAVIOR_EXTRACTION | code | fis/text_fingerprint.py, fis/repurposed.py, fis/pipeline.py |
| HUMAN_CONTINUITY_ANALYSIS | code | fis/continuity.py |
| NETWORK_ANALYSIS | code (batch) | fis/network.py |
| PRIMARY_SCORING | code (scores only, no action) | fis/scoring.py → engine.py (v0.5, frozen) |
| EVIDENCE_SUFFICIENCY | code | fis/coverage.py |
| SECOND_PASS | operator reads, code evaluates completion/result | operator_prompts/second_pass.md, fis/second_pass.py |
| DECISION_ENGINE | code — the only decision point | fis/decision_engine.py |
| OWNER_ADJUDICATION | owner ✅/❌ via template, code records | fis/adjudication.py |
| ENFORCEMENT | code plans/ingests; operator clicks | fis/enforcement.py, operator_prompts/block_batch.md |
| AUDIT_LOG | code | fis/evidence_store.py (every event carries 5 version stamps) |

Owner policy (`fis/owner_policy.py`) is a layer over the generic rubric. Schemas: `fis/schemas/`. Versions: `fis/versions.py`.
Instances (one per owner) live in `instances/<handle>/`; `instances/_template/` holds the neutral starter files. Product layer: `fis/hbg.py` (instances, modes, start line), `fis/autoblock.py` (decision-v0.7.0 tiers),
`fis/owner_model.py` (per-instance owner-trained model), `fis/scout.py` (Active Scouting), `fis/backtest.py`.

## Files

| Path | Role |
|---|---|
| `fis/` | The engine and CLI (`python3 -m fis <command>`) |
| `engine.py` | The frozen v0.5 deterministic scorer that `fis/scoring.py` wraps |
| `feature_registry.yaml` / `.json`, `rules/FEATURES.md` | Feature definitions and weights (generated by `tools/build_registry.py`) |
| `rules/SCORING_RUBRIC.md`, `rules/BASE_RULES.md` | Scoring and decision rules in prose |
| `validator.py`, `docs/SECOND_PASS.md` | Second-pass (disconfirmation) rules |
| `fingerprints_db.json` | Network fingerprint rules; ships with no clusters (each install builds its own) |
| `schemas/*.schema.json`, `jsonschema_lite.py` | Record, fingerprint, calibration and second-pass schemas plus a stdlib validator |
| `docs/COLLECTION_PROTOCOL.md`, `operator_prompts/` | What the browser operator samples, and the hard stops |
| `docs/METRICS.md`, `fis/metrics.py`, `fis/calibration.py` | Metrics, frozen calibration sets, rule-change gate |
| `instances/_template/` | Neutral starter files; each owner gets `instances/<handle>/` |
| `tools/build_registry.py`, `tools/build_schemas.py` | Regenerate the registry and schemas |
